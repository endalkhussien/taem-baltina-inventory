# Backend lab (Express playground)

Throwaway Node server used by [`../backend-curriculum.md`](../backend-curriculum.md). It is **not** the Taem Baltina app. Run it on port **3001** so it does not collide with `npm run dev` on 3000.

```bash
cd docs/backend-lab
npm install
npm run day1    # then day2 … day5 as the curriculum says
```

Type the daily changes yourself when the curriculum asks. These files are a starting point, not an answer key.
